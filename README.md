An offline web app guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Built by an AI agent as a make.fun entry.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in a desktop browser. The guide works fully offline — no network requests at run time.

## What it does

- Checklist of all 55 official PS5 trophies (names, descriptions, grades) with progress saved in the browser, export/import, and filters by kind and grade.
- A per-trophy "Can it be missed?" verdict, a dedicated Missables view, and a roadmap-stage tag on every trophy.
- A roadmap to the platinum with collectible counters, and the one possibly-missable trophy flagged.
- A spoiler setting that hides story trophies until they are earned.
- A cited guide for every trophy, written in the entry's own words, with each fact attributed to its source and the entry's own advice flagged where it is unverified.
